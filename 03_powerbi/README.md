# Power BI Reports & Dashboards

## Overview

This folder contains the Power BI dashboard developed for the E-Commerce Data Warehouse project.

The dashboard transforms the processed e-commerce data into interactive visualizations to support the analysis of sales performance, customers, products, payment amounts, and shipping operations.

## Dashboard KPIs

The dashboard currently includes the following key performance indicators:

- **Total Revenue:** Overall revenue generated by sales.
- **Total Orders:** Total number of orders.
- **Total Customers:** Number of customers represented in the data.
- **Units Sold:** Total quantity of products sold.
- **Payment Amount:** Total payment amount recorded in the payment data.
- **Average Delivery Duration:** Average recorded delivery duration in days.

## Visualizations

The dashboard includes visualizations for:

- Revenue by month
- Revenue by product category
- Revenue by sales channel
- Revenue by product

Interactive filters allow users to explore the data by:

- Year
- Month
- Country
- Customer segment
- Sales channel
- Product category

## Data Model

The report uses data from the E-Commerce Data Warehouse, which follows a dimensional modeling approach.

The warehouse contains three fact tables:

- `FactSales`
- `FactPayment`
- `FactShipment`

The dimensions provide descriptive information about customers, products, dates, and orders.

## Tools & Technologies

- Microsoft Power BI Desktop
- Microsoft SQL Server
- SQL
- Dimensional data modeling

## Planned Enhancements

Potential future improvements include:

- Gross profit and gross profit margin
- Average order value (AOV)

These metrics are planned enhancements and are not currently presented as implemented dashboard KPIs.
